Schedules & stages

Schedules compose aq verbs (cron, sweep, resume, pipeline, agents). Stages are nested full trains under stages/<name>/ - each with its own instructions.md and recipe.yaml.

PrerequisiteA train folder

aq schedule

List schedules under schedules/. tick runs due cron/resume entries; run fires one now.

example 
$aq schedule
example 
$aq schedule tick
example 
$aq schedule run nightly

aq stage

List, scaffold, train, or eval nested trains under stages/.

example 
$aq stage init prep
example 
$aq stage prep
example 
$aq stage eval prep
example 
$aq stage
