# v0.0.4 — to be shipped

## New

- **Machine-aware compute** — probes VRAM; VLMs no longer hardcode float32. Auto bf16/fp16, batch, gradient checkpointing; OOM auto-retry shrink.
- **Windows install** — `npm run build` no longer uses Unix `mkdir -p`/`cp`; installer handles Git Bash, `Scripts/` venvs, and `aq.cmd`.

## Fixes

- **VLM vision towers** — `vision:` accepts full ViT sizes (`vit-h/14`, `ViT-H-14`, …) and optional OpenCLIP weights via `vision_pretrained` / `pretrained` (`open-clip-torch`).
- **`aq serve` for every method** — `generate()` on VLM (LLaVA/Flamingo/CLIP), vision CNN/ViT, and tabular; `--image` / `serve.image` for multimodal. LLM methods unchanged.
