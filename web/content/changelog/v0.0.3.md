# v0.0.3 — to be shipped

## New

- **Vision CNNs** — `family: vision` / `method: cnn` with real aq-owned arches: LeNet, AlexNet, VGG, ResNet, Inception, EfficientNet, ConvNeXt. ImageFolder or path+label table. Train, eval (accuracy), inspect.
- **Vision transformers** — `method: vit` with aq-owned **ViT**, **Swin**, **DeiT** (CNN teacher distillation), **BEiT** (discrete VQ tokenizer → blockwise MIM → classify). Same ImageFolder data as CNN.
- **Train TUI** — on a real terminal, `aq train` shows a live dashboard (progress bars, stats columns, step table with highlighted latest row). Piped/CI stays plain tables. `AQ_TUI=0` turns it off.
- **Eval TUI** — `aq eval` gets its own scoreboard (metric / score / verdict / ckpt + probe table), not the train monitor.

## Fixes

- **`speculative: true`** — assisted decode actually works at serve. Set a smaller **`draft_model:`** (same tokenizer family).
- **`formats: true`** — real weight export after train (merged HF + **GGUF**; **GPTQ/AWQ** on CUDA; **EXL2** if convert.py is set). Prefer `formats: [gguf]` on Mac.
