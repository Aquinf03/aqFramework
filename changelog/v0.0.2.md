# v0.0.2 — unreleased

Work in progress. Edit this file as we ship changes; cut the release when ready.

## New

- **`aq plot`** — matplotlib charts from train artifacts: loss/lr (`metrics.jsonl`), job status (`jobs/`), run comparison (`artifacts/runs/`). Optional `plot:` block in `recipe.yaml` (`auto: true` plots after train). Global defaults in `~/.aq/config.json`. Agent: **`plot`** tool and **`aq_plot`**; new trains get `tools/plot.py` and `skills/plot-charts.md`.
- **`aq spawn --kill`** — optional cheapest-disproof critic worker (background agent job).

## Fixes

- **`connections/` removed from `aq init`** — external hooks belong in `tools/` (or MCP via `skills/`). Same slot, one convention.
- **`memory/` removed from train folder** — agent memory now lives in `~/.aq/memory/` (one thread per train, like chats). Old `train/memory/*.md` migrates on first use.
- **`methods/` removed from train folder** — custom fit goes in `tools/<method>.py` with a `fit()` function (same file can be `aq tool`). Kernel built-ins stay in `aq/kernel/methods/`.
- **`sandbox/` removed from `aq init`** — unused slot; agent can write anywhere in the train via file tools.
- **`schedules/` merged into `jobs/plans/`** — use `aq job plan` (cron, sweep, pipeline, resume, agents). `aq schedule` aliases to `aq job plan`.
- **`instructions.md` renamed to `experiment.md`** — human intent / brief for the train. Old `instructions.md` migrates to `experiment.md` on first `assertTrain` (status, train, etc.).
- **`train.ts` removed from `aq init`** — unused placeholder; trains are `experiment.md` + `recipe.yaml` only.

- **Agent chat from a non-train folder** — after `aq init`, status/train no longer pretend the folder was never created. Pass the new train name (`aq train tiny-char-model`) from the parent directory. The agent keeps the current request, remembers tools it already ran this turn, and recovers from “cwd is not a train” instead of going blank.
- **Agent waits for you** — “I wanna train a small model” is a conversation, not a blank check. Tools stay off until you say go; it won’t chain create → train → eval in one breath.

- **Boosting + CatBoost / LightGBM** — installed by default with the kernel (`library: catboost` and `library: lightgbm` work after install). Existing installs: `~/.local/share/aquin-framework/aq/kernel/.venv/bin/pip install catboost lightgbm` or re-run the install script.
- **Transformer trains (including distilled)** — fixed “Asking to pad but the tokenizer does not have a padding token”. Update `aq` (re-run the install script or pull latest), then re-run the train — no recipe changes needed.
- **MLM on Llama / GPT** — `objective: mlm` no longer requires a BERT checkpoint. Causal models (e.g. Llama) train with masked-token loss; BERT still uses full bidirectional MLM when you pick a BERT-class `model:`.
- **MTP** — `objective: mtp` with `n_predict: 2` (or higher) trains real multi-token prediction heads on a causal LM. Set `n_predict` in the recipe; re-run the train after updating `aq`.
- **`paged_kv: true`** — no longer blocks training. Flag is recorded; `aq serve` uses standard Hugging Face KV cache (not paged attention yet). Same for `speculative: true` during train.
